# tools

一些自用的小工具和脚本。都是为了解决自己遇到的具体问题写的，顺手放出来。

## 目录

### 用户脚本（Userscripts）

需要 [Tampermonkey](https://www.tampermonkey.net/) 之类的脚本管理器。

| 脚本 | 做什么 |
|---|---|
| [微博宽屏版](userscripts/weibo-wide) | 让 weibo.com 的正文区跟着窗口自适应变宽，纯 CSS 弹性布局，缩放实时跟手。竖屏显示器上尤其有用 |
